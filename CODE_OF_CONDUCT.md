# Code of Conduct

## Our Standard

This project expects respectful, technically focused collaboration.

Examples of expected behavior:

- Discuss code, behavior, and evidence directly.
- Assume good intent while still challenging weak technical arguments.
- Share review feedback in a way that helps move the work forward.

Examples of unacceptable behavior:

- Harassment, personal attacks, or discriminatory language
- Intimidation, doxxing, or sustained disruption
- Deliberately hostile or bad-faith participation

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject comments, commits, issues, or pull requests that violate this code of conduct.

## Reporting

Report conduct issues privately to the project maintainers through the repository host's private contact channel. Public escalation should be avoided until maintainers have had a chance to respond.
