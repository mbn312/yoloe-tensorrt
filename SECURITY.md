# Security Policy

## Supported Versions

Security fixes are expected on the latest development branch and the latest tagged release.

## Reporting a Vulnerability

Do not open a public issue for suspected vulnerabilities.

Until a dedicated security contact is published in the repository hosting settings, report security issues privately to the repository maintainers through the private contact channel associated with the project. Include:

- the affected version or commit
- the deployment environment
- reproduction steps
- the expected and observed behavior
- any mitigations already identified

This file should be updated with a dedicated security email or reporting form before the first public release.
